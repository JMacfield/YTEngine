# YTEngine
### 概要
2023年4月～今現在までの約22カ月の間


制作しているDirectX12APIを使ったゲームエンジンです。
### 特徴
WinSock2を利用したネットワーククラス・ネットワークマネージャー


TCP/UDP通信・同期・ノンブロッキングI/O  
といった通信に関する様々な機能があります。
